# BGM・効果音の置き場所

このディレクトリには、TSF シナリオとサロン経営の BGM、サロン経営の効果音を置きます。
どの音を使うかは `catalog.json` に登録します（キー・ファイル名・説明・出所の表記）。

BGM の音声ファイルはリポジトリに含めています。効果音だけは、次の理由でリポジトリに含めていません。

## サロンの効果音（リポジトリに含めない）

サロン経営の効果音には、外部サイトの素材を使っています。素材そのものを再配布しないよう、
音声ファイルは `.gitignore` で除外し、配布用パッケージにだけ同梱します。
`catalog.json` への登録はリポジトリに含めているので、ファイルを置くだけで鳴ります。

| ファイル名                | 鳴る場面                                 | 素材                                     |
| ------------------------- | ---------------------------------------- | ---------------------------------------- |
| `se01_salon_register.ogg` | 会計で、お支払いが HUD の現金に届いたとき | OtoLogic「レジ ドロワー02」              |
| `se02_salon_ledger.ogg`   | 開業・週の締めの演出の、帳簿の幕         | OtoLogic「本03」                         |
| `se03_salon_doorbell.ogg` | 開業・週の締めの演出の、開店の幕         | ポケットサウンド「ドアベル＃3「チリン」」 |

## 配布用パッケージを作る前に

1. 各サイトから素材をダウンロードする。
   - [OtoLogic](https://otologic.jp/)（[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)）
   - [ポケットサウンド](https://pocket-se.info/)
2. OGG 形式（Ogg Vorbis）に変換する。サーバーは `audio/ogg` として返すので、拡張子を変えただけのファイルはブラウザによっては鳴りません。
   - 例: `ffmpeg -i ダウンロードした音声 -c:a libvorbis -q:a 5 se01_salon_register.ogg`
3. 上の表のファイル名で、このディレクトリに置く。
4. ビルドスクリプトを実行し、「✓ サロンの効果音を同梱」と出ることを確かめる。
   - Windows: `scripts/build_portable.ps1`
   - Linux: `scripts/build_portable_linux.sh`

ビルドスクリプトは `backend/gateway` をまるごとコピーするので、このディレクトリに置いたファイルがパッケージに入ります。
足りないファイルがあると「! サロンの効果音が見つかりません」と出ます。ビルドは止まらず、その音が鳴らないだけです。

## 置かないとき

ファイルが無い音は、BGM カタログの API（`GET /api/adventure/bgm`）が返さないので鳴りません。
1つも無ければ、サロンの ♪ パネルに効果音の欄も出ません。ソースからの起動・開発・テストには影響しません。

## クレジット

利用条件は各サイトの規約に従います。CC BY 4.0 の素材は、作者・ライセンス・加工したことの表示が必要です。
素材を差し替えたときは、次の表記も合わせて直してください。

- 配布用 README の「使用している音声素材（クレジット）」: `scripts/templates/README.txt`・`README_en.txt`・`README_linux.txt`・`README_linux_en.txt`
- `catalog.json` の各効果音の `credit`（BGM テスト画面に表示されます）

## 注意

`git clean -x`（または `-X`）は、Git から除外したファイルも消します。このディレクトリの効果音も消えるので、実行するときは気をつけてください。
