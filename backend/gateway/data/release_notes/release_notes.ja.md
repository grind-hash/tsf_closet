# TSF Closet 更新履歴

## v0.12.0 (2026-11-28)

### 新機能

- 箱庭を追加（実験的機能）
  - 小さな下宿「星屑荘」で、住民たちのやりとりを気ままに見守るモードです。ゴールや決まった目的はありません
  - 時間が進むのは「1日進める」を押したときだけです。その日の出来事が3件生まれ、住民が部屋に寄り合って吹き出しで話します。出来事は年代記に残り、1日の終わりには「N日目のまとめ」（今日の山場・大きく動いたこと・明日の予感）が出ます
  - 住民をクリックするとひとことをしゃべり、「チャットする」で何往復でも話せます。「〜に着替えて」「元に戻して」と頼むと、その場で変身・元に戻します。話す内容で住民のあなたへの好感度が上下します
  - 掟（お嬢様言葉の掟・入れ替わりの朝・ドレスの掟・恋愛禁止令・告白週間と、自分で書いた掟）を同時に3枚まで有効にでき、次の日からの出来事すべてに効きます。「世界のメモ」や住民の「改変」で、世界の常識を書き換えることもできます
  - 住民は星屑荘の5人のほか、キャラクター画面で作ったキャラクター（立ち絵があるもの）、自分で書いた住民、「おまかせの住民」から迎えられます
  - 「出来事を指示する」で、書いた指示どおりの場面を住民のいまの姿のまま生成できます。年代記の「ADVで見る」で、出来事を背景と立ち絵のついた画面で1幕ずつ読め、「場面の絵を生成」で出来事に出た住民が並ぶ絵を1枚描けます
  - 星屑荘にはリビング・庭・書斎・台所・衣装部屋があり、「家具」タブで場所ごとに家具を4つまで置けます
  - 「住民とあなた」で、住民があなたを最初から知っている「顔なじみ」か、姿の見えない「見えない存在」かを選べます。「世界の違和感」を使う世界では、掟の切り替えや変身を重ねるほど住民が世界の書き換えに気づいていきます
  - 任意で、世界の設定の「Web検索を利用する」をONにすると、会話や出来事に最近の話題を取り入れます。config.env の TAVILY_API_KEY の設定が必要で、検索1回につき Tavily のクレジットを1消費します
  - 箱庭用の BGM（1曲）を追加しました。BGM は初めは OFF で、上端のバーの ♪ から ON にできます
  - 箱庭での観察（日数・出来事・掟・変身など17項目）は、「実績」画面の「箱庭」に記録されます
  - 出来事・ひとこと・チャットにはテキスト生成を、変身・姿・場面の絵には画像生成を使うため、その分の待ち時間がかかります
  - 設定画面の「Experimental（実験的機能）」にある「箱庭」をONにすると、メニューに表示されます。新しく作る世界の既定は、設定画面の「箱庭」で決められます
- NAI Diffusion V5 で精密参照を使えるように
  - これまで V4.5 系専用だった精密参照が、V5（Full・Curated）でも使えるようになりました。V5 Full の節約モードでは使えません
  - V5 では参照の種類に「衣装」が加わり、キャラクター＆絵柄・キャラクターの参照では「衣装も参照する」を選べます（初期値はOFFで、服は指示どおりに描きます）。強度は5.0まで上げられます
  - V5 ではインペイント（マスク使用）の手番に精密参照は送られません
  - 精密参照の画像は、アップロードのほか「一覧から選ぶ」でセッション・お気に入り・Prompt Expander・キャラクターの立ち絵から選べます
  - 参照1枚につき5 Anlasを追加で消費します（送信前に確認が出ます）
- TSFシナリオで、遊んだシナリオの設定を写して新しく作れるように
  - 「保存されたシナリオ」の「設定を写して新しく作る」を押すと、開始セッション・ミッション・舞台・ゴール・制約・物語の演出・主人公・呼び名・日数（ターン数）が作成画面に入ります。始める前に書き換えられます
- Prompt Expander の入力欄と精密参照を刷新（実験的機能）
  - プロンプトの入れ方を「LLMで作る」と「直接書く」から選べるようになりました。LLMで作るでは、指示（漫画モードではあらすじとネーム）とプロンプトの欄が分かれ、指示を書き換えずにプロンプトを何度でも作り直せます
  - 漫画モードの「あらすじからネームを下書き」は、あらすじを残したままネーム欄に案を入れるようになりました
  - 精密参照を最大6枚まで足せるようになり、画像ごとに種類と強度を決められます。参照に名前と外見タグを付けると登場人物になり、プロンプト化やネームの下書きで使われます。複数の人物を描き分けられるのは V5 だけです（2人以上なら強度0.5前後がおすすめです）
  - エントリの「キャラクターにする」で、その画像を立ち絵にしたキャラクターを作れます
  - 指示やネームの欄で Ctrl+Enter（Mac は ⌘+Enter）を押すとプロンプト化（あらすじではネームの下書き）、Ctrl+Shift+Enter で生成します。画面下の生成バーのチップから、その設定の欄へ移れます
  - 書きかけの欄はセッションごとに残り、ほかのセッションへ移ったりページを再読み込みしたりしても戻ります（タブを閉じると消えます）

### 改善

- キャラチャットのセレナに、アプリの更新内容を聞けるようにしました（「最新で何が変わったの？」「キャラチャットはいつ追加されたの？」など）。同梱の更新履歴を調べて答えます
- サロン経営で、開店画面とオーナー室の「来客の種類」から、お客様の性別と願う体を選べるようにしました。お客様の性別を「男性」、願う体を「女性」にすると、女の子になりたい男性だけが来店します
- サロン経営の過激施術（成人向け）で、お客様の設定や来店時の姿に子どもを思わせる要素があるときは全年齢の依頼にし、施術後の姿や願いにあるときはお披露目の夢を描かないようにしました
- キャラクター画面の一覧に「並び順」（作成日・名前）を追加しました。選んだ並び順は、精密参照やTSFシナリオなどでキャラクターを選ぶ画面にも使われます
- TSFシナリオの開始セッションを選ぶ画面で、選択中のセッションを先頭に表示し、各セッションの枚数と開始日を表示するようにしました
- 配布パッケージの依存ライブラリを、開発で動作を確かめた版（ロックファイルに記録した版）のとおりに入れるようにしました（サプライチェーン攻撃対策）
- 依存ライブラリを更新しました

### 非推奨

- 新規プレイの「または自分の画像を使用」を削除しました（v0.11.0で非推奨化）。画像からプレイを始めるときは、キャラクター画面で立ち絵に画像をアップロードし、「このキャラでプレイ」から始めてください
  - 以前に「自分の画像を使用」で作ったキャラクターは、起動時にキャラクター画面へ自動で取り込まれます（名前・一人称・性格・外見タグなども引き継ぎます）
  - あわせて、Prompt Expander のエントリの「通常プレイで使う」を削除しました。代わりに「キャラクターにする」でキャラクターを作り、「このキャラでプレイ」から始めてください

## v0.11.1 (2026-11-10)

### 不具合修正

- 前のバージョンからデータを引き継いだTSFシナリオで、画像が生成されない不具合を修正
  - 旧バージョンで始めたシナリオを続けると「立ち絵の生成に失敗しました」「アドベンチャー画像が見つかりません」と表示され、立ち絵・場面画像を生成されなかった問題を対応
  - 攻略対象の立ち絵や、過去の場面を見返したときの背景が表示されない問題もあわせて修正
  - キャラチャットで、引き継いだシナリオの攻略対象と会話を始められない問題も修正

## v0.11.0 (2026-11-06)

### 新機能

- サロン経営モードを追加（実験的機能）
  - お客様の願いを着せ替えで叶えて、サロンを経営するモードです。1期は4週（短め）か12週（じっくり）から選べ、決算のあとは現金と評判を持ち越して次の期へ続けられます
  - 開店時に経営の難易度（やさしい・ふつう・むずかしい）と営業期間を選びます。難易度と期間で開業資金が変わり、毎週の固定費を接客の売上で埋め合わせて、期末に期首を上回る現金を残すと成功です
  - 接客は依頼モードと同じ仕組みです。カウンセリングの質問（2回）でお客様が口にしない好みの手掛かりを聞き出し、3手の施術で仕上げます。会計の満足度から売上と評判が決まり、評判が上がると予約と、願いを叶えたときのチップが増えます
  - 満足度100の仕上がりは施術料が倍になり、姿を持ち越して続けて来た常連の願いを叶えると指名料も付きます。まだ施術していないお客様には「お帰りいただく」（評判 −3）を選べます
  - 接客画面には満足度（前の施術からの増減と達成の線）と、お客様が口にしない好みの分類を並べたカルテが表示されます。カウンセリングではカルテの分類を押すと、その分類について質問を書き込めます
  - オーナー室で、現金の推移や口コミを確認できます
  - 接客画面の ⚙ から、直接プロンプト・ネガティブプロンプト・i2i 強度・画像とテキストのモデルを変えられます（通常プレイの右パネルと共通の設定です）
  - 施術の指示欄の「範囲を選ぶ」で、描き直す範囲を手描きやマスクで指定できます（NovelAI のみ）。施術中は「見比べる」で、直前の姿やご来店時の姿と並べて比較できます
  - 開業と週の締めには演出が入り、オーナー室でフル・短い・なしを選べます。サロン経営用のBGM（3曲）と効果音を追加しました
  - 「過激施術（成人向け）」をONにすると、成人向けの願いを持つお客様が来店し、お披露目でその姿で願いが叶うひとときの夢を1枚見せます。NSFW モードがONのときだけ有効です
  - キャラクター画面で立ち絵を用意したキャラクターも、お客様として来店します（キャラクターごとの「サロンに来店する」で切り替えられます）
  - 施術ごとに画像を生成し、質問と口コミにはテキスト生成を使うため、その分の待ち時間がかかります
  - 設定画面の「Experimental（実験的機能）」にある「サロン経営」をONにすると、メニューに表示されます
- 依頼モードを追加
  - 新規プレイの画面で「依頼モード」を選ぶと、キャラクターが「なりたい姿」を依頼してきます。着せ替えで願いを叶え、満足度を上げて依頼達成を目指します
  - 伏せられた好み（？？？）は、キャラクターの反応やヒントから推理します。「カウンセリング」で依頼主に質問して、手掛かりを聞き出すこともできます
  - 「施術の手数」で、着せ替え・現実改変ができる回数（上限なし・3手・5手）を選べます。行動や会話は数えません
  - 最初の着せ替えの前だけ、「別の依頼にする」で依頼を作り直せます
  - 自分自身モードでは依頼は届きません
  - 依頼の作成と質問への回答にテキスト生成を使うため、その分の待ち時間がかかります
- キャラクター画面を追加
  - メニューの「キャラクター」から、キャラクターを作って管理できます。名前・一人称・性格・口調・セリフの例・知識・背景・外見・3D モデル・声・最初のひとことを設定できます
  - 立ち絵は「画像をアップロード」（画面のどこへドロップしても可）、「素材の画像を立ち絵にする」（セッション・お気に入り・Prompt Expander の画像）、「外見タグから立ち絵を描く」で用意できます。「精密参照を使う」をONにして描くと、参照1枚あたり Anlas を追加消費します
  - 「LLM で性格を下書き」で、名前・外見・メモから性格・一人称などを埋めます。メモに話し方やセリフの例があれば、「口調・話し方」「セリフの例」にも入ります。「外見の自然文からタグを作る」で外見タグを作れます
  - 立ち絵があるキャラクターは「このキャラでプレイ」から、自分自身モードや依頼モードを選んでプレイを始められます
  - 「このキャラと話す」でキャラチャットを始められます。作ったキャラクターは、TSFシナリオの開始素材・主人公、サロン経営のお客様、通常プレイの登場人物にも使えます
  - キャラチャットをOFFにしていても、キャラクター画面は使えます
- TSFシナリオに「改変の代償」を追加
  - ONにすると、現実改変を確定させるたびに、その改変から生じる予期せぬ代償が1つ生まれます（例: 豪邸の主になる → 固定資産税の通知が届く）
  - 代償は自分の行動で解決するまで物語に残り、現実改変では消せません。未解決の代償を残したまま目標を達成すると、部分的な成功になります
  - 恋愛シミュレーションでは代償が請求として届き、所持金から支払うと解決します（手番は使いません）
  - HUD の「改変の代償」から、代償の一覧と、どの現実改変から生じたかを確認できます
  - 既定はOFFです。TSFシナリオの開始画面か、プレイ中の「画像生成設定」からONにしてください
- TSFシナリオで、キャラクター画面のキャラクターを使えるように
  - 開始素材の選択に「キャラクター」タブを追加しました。立ち絵があるキャラクターを選べます
  - 選んだキャラクター本人として遊ぶと、名前・性格・口調・知識が主人公に反映されます。恋愛シミュレーションでは、選んだキャラクターが攻略対象になります
  - 恋愛シミュレーションの主人公にも、「作ったキャラクターを使う」でキャラクターを選べます

### 改善

- キャラチャットを実験的機能から通常の機能にしました
  - 既定でONになり、メニューに表示されます。不要な場合は設定画面の「キャラチャット」からOFFにできます
  - キャラクター画面で作ったキャラクターと話せるようになりました（「作ったキャラクターと話す」）
  - 過去セッションの人物に、作ったキャラクターの設定（性格・口調・知識など）を重ねられます。いまの名前と姿からキャラクターを作ることもできます
  - 「表情」メニューで表情を試せます。2D 立ち絵では表情差分（表情だけを変えた立ち絵）を描けて、返答の表情に合わせて自動で切り替わります。表情ごとに1枚ずつ画像を生成し、精密参照を使う場合は参照1枚あたり Anlas を追加消費します
  - 3D モデルの表示中に、ライティング（標準・明るめ・夕暮れ・夜）とカメラ（全身・上半身・顔）を切り替えられます。ライティングはTSFシナリオと設定のプレビューにも反映されます
- 3D モデルの揺れもの（髪など）の当たり判定を、読み込んだモデルに合わせて補正するようにしました
- 新規プレイで選べるキャラクターを2人追加しました
- ギャラリーに、セッションの種類（すべて・通常プレイ・サロン経営）で絞り込む機能を追加しました。サロン経営の接客は、既定では「サロン経営」の絞り込みでだけ表示します（設定画面の「ギャラリーの「すべて」にサロン経営の接客を含める」で切り替えられます）
- お気に入りプロンプトのカテゴリーを削除するときに、中のお気に入りプロンプトもまとめて削除できるようにしました
- 依頼モードとサロン経営の実績（8件）を追加しました
- 遊び方ガイドに、通常プレイ・ギャラリー・キャラクター・エンディングと実績・設定の説明を追加しました

### 非推奨

- 新規プレイの「または自分の画像を使用」（v0.12.0で削除予定）。画像からプレイを始めるときは、キャラクター画面の「画像をアップロード」で立ち絵を置き、「このキャラでプレイ」から始めてください。「自分の画像を使用」で作ったキャラクターは、キャラクター画面の「このキャラクター画面へ取り込む」で移せます

## v0.10.0 (2026-10-24)

### 新機能

- 登場人物の設定を刷新（実験的機能）
  - 登場人物パネルの「登場人物を編集」から、主人公を含めて最大22人まで登録できるようになりました（従来は4人まで）
  - 人物ごとに、外見（自然文・NovelAI形式のタグ）、ネガティブタグ（この人物に描かないもの）、立ち位置（左・中央左・中央・中央右・右）を設定できます。「自然文からタグを作る」で外見タグを作成でき、「姿を選ぶ」で過去のセッションから姿を読み込めます（Prompt Expander 有効時は Prompt Expander のキャラクターからも選べます）
  - 人物ごとに性格を設定できます。「メモから性格を生成」で、性格メモ（空なら名前と外見）から性格を作れます。性格を設定すると、その人物の一人称や口調が文章に反映されます
  - 登場中の人物が、画像生成だけでなく心の声・行動・チャットの文章にも反映されるようになりました
  - 名前を挙げた指示は、その人物に効くようになりました。指示を受けた人物は個別にパラメータが進み、指示の対象外の主人公は今の姿のまま描かれます
  - 「姿を固定」で毎回設定どおりに描き、「効果対象外」で指示の影響を受けないようにできます。「登場」のON/OFFで、登録したまま場面から外せます
  - 指示で変わった姿は次の手番に引き継がれます。「現在の姿」から、今の姿を設定にコピーしたり、設定の姿に戻したりできます
  - 1枚の画像に描ける人数は、NAI Diffusion V5 で22人、それ以外のモデルで6人までです
  - 「組み合わせ」で主人公以外の登場人物をまとめて保存し、別のセッションで呼び出せます。キャラクタープリセットを主人公に適用できるようにもなりました
  - 設定画面の「Experimental」にある「複数人表示（実験的）」をONにしてください
- お気に入りプロンプトを追加
  - よく使うタグや指示文に名前を付けて保存し、入力欄へ挿入できます。名前にカーソルを合わせると内容を表示し、クリックすると入力欄に挿入します
  - 着せ替えなどの指示欄、直接プロンプト・ネガティブプロンプト欄、登場人物の設定、TSFシナリオの自由入力と場面画像のプロンプト編集、キャラチャット、Prompt Expander から使えます。各入力欄の保存ボタンから、今の入力内容を登録することもできます
  - カテゴリー（色分け）で整理でき、ドラッグ＆ドロップで並べ替えやカテゴリーの移動ができます。すべてのカテゴリーをまとめて開閉することもできます
  - CSV / JSON ファイルへの書き出し・読み込みに対応しています。CSV は Excel や Google スプレッドシートで編集できます。読み込み時、同じカテゴリー・同じ名前の項目は確認のうえ上書きします
  - お気に入りプロンプトは TSF Closet 内に保存され、**NovelAI のプロンプトチャンクには登録されません**
