# 同梱の更新履歴

`release_notes.ja.md` は、案内役キャラ「セレナ」が「最新で何が変わったの？」
「この機能はいつ追加された？」に答えるための更新履歴。

- **先頭の版がアプリの「いま使われている版」になる。** 版番号の置き場所はこのファイルだけ。
  セレナには毎回「いま使われているバージョンは vX.Y.Z」の 1 行だけを渡し、本文は
  判定 LLM が調べ物 `app_updates` を選んだ手番にだけ、該当する版・項目を載せる。
- リリースのたびに、GitHub 用リリースノートの本文を**先頭に**追記する（新しい版が上）。
  「Special Thanks」「Full Changelog」「素材のクレジット」の節と、冒頭の
  「TSF Closet vX.Y.Z をリリースしました。」の行は入れない。
- 形は GitHub 用と同じ。`## vX.Y.Z (YYYY-MM-DD)` → `### 新機能` などの見出し → 箇条書き
  （2 段目はインデントした `-`）。この形以外の `## ` 見出しは置かない
  （`tests/unit/test_release_notes.py` で確かめている）。
- 日本語版だけを同梱する。英語の会話でも同じ文面を渡し、セレナが英語で答える。
- ポータブル版のビルド（`scripts/build_portable*.{sh,ps1}`）は、`-v` の版がこのファイルの
  先頭の版と食い違うと止まる。
- 読み込みは `gateway/services/release_notes.py`。ファイルの更新時刻が変わると読み直すので、
  サーバーの再起動は不要。
