# v0.6.0 Experimental: プレイメモ

## 目的

セッションごとの経緯と現在状況を自動要約し、ユーザーが追加したメモとともに、以後の生成へ反映する。

## 要件

- 設定画面の Experimental トグルは既定で無効とする。
- 有効時だけ右パネルへ、自動メモとユーザーメモを表示する。
- 両メモはセッション単位で保存し、それぞれ個別に有効化できる。
- 自動メモは着せ替え、現実改変、行動、会話の正常完了後にローリング更新する。
- 自動メモの更新失敗は本来の操作を失敗させず、以前の内容を保持する。
- 手動再生成は現存する全履歴と会話を対象にする。
- 今回の指示、ユーザーメモ、自動メモ、好みメモリの順に優先する。
- 履歴提案、テキスト生成、画像プロンプト生成へ同じ文脈を反映する。

## 受け入れ条件

- 無効時は既存クライアントと同じ結果になり、プレイメモを更新・注入しない。
- セッションの取得・復元後も本文と個別トグルが維持される。
- 個別トグルを無効にしても本文は削除されない。
- ユーザーメモは4,000文字以内で明示保存できる。
- 自動メモは右パネルで閲覧・再生成できるが直接編集できない。
