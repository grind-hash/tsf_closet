### 見つかった問題と対応

初回の生成では、V5 Full・Mediumとも同じ人物が横に2人並び、Mediumでは2人目が着衣と裸の比較のような絵になった。
共通の画像生成が正のプロンプトへ足す英文の接尾辞（`no before/after panels, no side-by-side comparison, no twins, no clones` など）が、タグで学習したモデルでは否定として効かず、その語に引っ張られたと判断した。

- 箱庭のアバターだけ生プロンプト（`raw_prompt`）で送り、接尾辞を付けない。重複を避ける語はネガティブ側にだけ置く。
- `nsfw` タグはユーザーの指定で残す（NSFWモードの描かれ方はそのまま）。
- 保険として、生成後に左右へ並んだ人物を透過マスク（白背景なら背景色との差）の列の分布から検出し、1人だけを中央に置き直す。手が触れて列が途切れない場合も、中ほどの深い谷で分ける。

修正後に V5 Full・Medium を各1枚生成し直し、生の出力の時点で1人になること（保険の処理が働かないこと）を確認した。

## 関わり方の実モデル確認（2026-11-09）

隔離した一時DB（NSFWモードON）で NovelAI のテキスト（glm-4-6）と NAI Diffusion V4.5 Full の既定の設定で確認した。画像は会話からの変身の1枚だけで、実行前後の Anlas は 16416 のまま変わらなかった。

| 確認 | 結果 |
| --- | --- |
| 世界のメモ（真冬で毎晩雪、暖炉） | その日の出来事3件と、会話からの変身の反応のすべてに雪と暖炉が出た |
| 掟の相性（入れ替わり×ドレス） | 入れ替わった体のまま相手のドレスを着ている場面として描かれた |
| 明日の介入（書き換えを強める） | まとめに介入の結果が出て、違和感が +5 された（掟2枚の +16 と合わせて 21） |
| タッチ（ドレス姿の男性住民の頭・胸） | 「なっ……頭、撫でないでくれ。」「うわっ…！な、何するんだ、急に。」。気分は +2 / −2 |
| 会話 | 入れ替わりとドレスを踏まえた返事。「メイド服に着替えて」は変身として実行され、「元に戻して」で元に戻った |

### 見つかった問題と対応

- 日本語の出力に簡体字（违和感・全然违う）が混ざった。プロンプトで具体例つきで禁止していても出るため、日本語の出力では日本語に無い簡体字だけを日本の漢字へ置き換える（`hakoniwa_text.normalize_output`）。机・叶のように日本語でも使う字は置き換えない。
- 入れ替わりで男性の体になった女性住民が、変身の反応で「俺」と言った。住民情報の入れ替わりの注記に「自分の一人称を使い、相手の一人称は使わない」と名指しで書くようにし、出来事2件と変身の反応2件で、両者とも本人の一人称のままになることを確かめた。
- 入れ替わり中に変身させたとき、文章は「（相手の体にいる）本人が変わった」と描くが、表示では本人の体（いま相手が入っている）の姿が変わる。移植元と同じ仕組みだったが、ユーザーの判断で「表示を文章に合わせる」に直した（次の節）。

## 入れ替わり中の変身と掟の即時反応の実モデル確認（2026-11-09）

変身は体に付き、その体にいる人が体験する、に揃えた。入れ替わり中に変身させると本人がいま入っている体のエントリへ保存し、文章・表示・住民の表示の変身はすべて、いまいる体から読む。入れ替わりが解けると、変身した体は持ち主に戻る。

隔離した一時DBで NovelAI のテキスト（glm-4-6）と NAI Diffusion V4.5 Full の既定の設定で確認した。画像は1枚で、実行前後の Anlas は 16406 のまま変わらなかった。

| 確認 | 結果 |
| --- | --- |
| 入れ替わり（葵と蓮）を有効にした直後の反応 | 蓮「……え？ この姿、高瀬 葵……？ 声まで高瀬 葵だ。なんで俺がこんなことに……」、葵「待って、私の声が苑田 蓮になってる……。鏡、鏡を見せて！」 |
| 入れ替わり中に葵へ「メイド服に着替えて」 | 変身は蓮の体のエントリに保存され、画像は蓮の体（緑の短髪の男性）のメイド服。部屋では葵の名札の姿が変わり、蓮の名札の姿（葵の体）は変わらない |
| 変身の反応の文章 | 「高瀬葵が……彼の身に着ていたカジュアルな服が……メイド服に」と、男性の体の葵として描かれ、葵の一人称は「私」のまま |

## おまかせの住民と実験テーマの実モデル確認（2026-11-09）

隔離した一時DBで NovelAI のテキスト（glm-4-6）と NAI Diffusion V4.5 Full の既定の設定で確認した。画像はおまかせの住民2人の立ち絵だけで、実行前後の Anlas は 16406 のまま変わらなかった。

| 確認 | 結果 |
| --- | --- |
| おまかせの住民（日本語3人・英語3人・入れ替え1人） | どれもテキストモデルで作れた。名前・年代・職業・一人称・外見の文と英語タグが対でそろい、入れ替えは除外した名前と重ならなかった |
| 立ち絵2人（順に生成） | 外見の文どおり（無精ひげに作業着とジーンズの男性、長い黒髪に灰色のニットと白い襟の女性） |
| 自由文のテーマ（住民みんなが少しずつ猫好きになっていく） | 1日のまとめに進み具合が出た。直したあとは、その日の出来事3件のうち1件だけが猫の話になった |

### 見つかった問題と対応

- 日本語の住民の年代が英語（early 30s）で返った。出力の例を言語ごとの値（20代後半）にした。
- 英語の住民の性格が一人称（I am a night owl...）で書かれた。三人称の説明で書くよう指示した。
- 日本語の職業に中国語（系统工程师）が混ざった。日本語の職業名の例を示し、日本語の欄に日本語に無い簡体字があれば修復を依頼する検証を足した（置き換え表にも 统・师 などを追加）。
- 自由文のテーマが、その日の出来事3件すべてに出た（「無理に入れない」と書いても同じ）。Python で1日1件だけにテーマを渡すようにした。
- 出来事の地の文に文字化け（部屋の�辺から）が1か所あった。NovelAI の応答そのものに含まれていた（受信は行単位で正しく復号している）。まれで、こちらでは直せない。
