============================================
  TSF Closet (Linux)  ─  はじめにお読みください
============================================

  TSF Closet をダウンロードいただき、
  ありがとうございます。

  このファイルでは、Ubuntu/Linux 環境での
  セットアップから遊び始めるまでの手順を
  説明しています。


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  初回セットアップ（はじめに必ず行ってください）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  このゲームでは、画像やテキストの生成に
  NovelAI のサービスを利用します。
  遊ぶには NovelAI の「APIキー」が必要です。

  ── NovelAI APIキーの取得方法 ──

  1. ブラウザで NovelAI 公式サイトにログインします
     https://novelai.net

  2. 画面左上の歯車アイコンをクリックして
     「アカウント」設定を開きます

  3. 「永続的APIトークンを取得」をクリックします

  4. 表示された長い文字列（pst- で始まるもの）が
     APIキーです。これをコピーしてください

     ※ APIキーは一度しか画面に表示されません。
       メモ帳などに控えておくことをお勧めします。
     ※ このキーは他人に教えないでください。

  ── config.env への設定方法 ──

  1. このフォルダ内にある「config.env」ファイルを
     テキストエディタで開きます

     例:
       nano config.env
       gedit config.env
       vim config.env

  2. ファイルの中に以下のような行があります:

       NOVELAI_API_KEY=your_api_key_here

  3. 「your_api_key_here」の部分を、
     先ほどコピーしたAPIキーに書き換えます

     例:
       NOVELAI_API_KEY=pst-abc123xxxxx...

     ※ = の前後にスペースを入れないでください
     ※ APIキーを「"」や「'」で囲まないでください

  4. 書き換えたら保存してください

  これで初回セットアップは完了です!


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  ゲームの起動方法
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1. ターミナルでこのフォルダに移動し、
     start.sh を実行します

     cd /path/to/tsf_closet_portable
     ./start.sh

     ※ 権限エラーが出る場合:
        chmod +x start.sh
        を実行してから再度お試しください

  2. ターミナルにログが表示され、
     しばらく待つと準備が整います

  3. 自動的にブラウザが開き、
     ゲーム画面が表示されます

  4. もしブラウザが開かない場合は、
     ブラウザのアドレスバーに
     以下のURLを直接入力してください:

       http://127.0.0.1:8000


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  ゲームの終了方法
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  以下のいずれかで終了できます:

  - ターミナル上で Ctrl+C を押す

  - 別のターミナルから stop.sh を実行する
    ./stop.sh


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  遊ぶのに必要なもの
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  - Ubuntu 22.04 以降 (64bit) またはその他の
    Linux ディストリビューション
  - インターネット接続
  - NovelAI の有料プラン（サブスクリプション）

  ※ NovelAI の有料プランに加入していないと
    画像生成やテキスト生成が行えません。
  ※ 画像生成ごとに NovelAI の Anlas を消費します。
    Opus プランでは通常サイズの生成が無制限です。


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  NovelAI のプランについて
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  このゲームで快適に遊ぶには
  「Opus」プランをお勧めします。

  理由:
  - 通常サイズの画像生成が無制限
  - テキスト生成（キャラクターの心境表示）も利用可能
  - Anlas（消費ポイント）の残量を気にせず遊べる

  Tablet / Scroll プランでも遊べますが、
  1回の画像生成ごとに Anlas を消費するため、
  月間の利用量に注意が必要です。


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  設定のカスタマイズ（上級者向け）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  config.env をテキストエディタで編集することで、
  以下のような設定を変更できます。
  通常はそのままで問題ありません。

  PORT
    サーバーのポート番号です（初期値: 8000）。
    他のソフトと競合する場合のみ変更してください。

  LOG_LEVEL
    ログの詳細度です（初期値: info）。
    問題が発生した場合に debug に変更すると、
    詳しい情報がコンソールに表示されます。

  NOVELAI_STEPS
    画像生成のステップ数です（初期値: 28）。
    大きくすると品質が上がる場合がありますが、
    生成時間が長くなります。

    ★ 重要 ★
    Opus プランでも、ステップ数を 29 以上に
    すると Anlas を消費するようになります。
    28 以下であれば Anlas 消費なしで生成できます。
    特にこだわりがなければ 28 のままにしてください。

  NOVELAI_I2I_STRENGTH
    画像の変化の度合いです（初期値: 0.90）。
    1.0 に近いほど大きく変化します。
    0.0 に近いほど元画像に近い結果になります。


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  データの保存場所
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  ゲームのセーブデータや生成した画像は、
  以下のフォルダに保存されます:

    backend/data/

  データをバックアップしたい場合は、
  このフォルダをまるごとコピーしてください。


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  よくある質問（トラブルシューティング）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Q: start.sh を実行しても「Permission denied」と出る

  A: 実行権限を付与してください:
     chmod +x start.sh stop.sh

  ─────────────────────

  Q: 「ポートが使用されています」と表示される

  A: 他のソフトが同じポート（8000番）を
     使っている可能性があります。
     config.env の PORT を別の番号
     （例: 8080）に変更してください。

     使用中のプロセスを確認するには:
       ss -tlnp | grep :8000
     または:
       lsof -i :8000

  ─────────────────────

  Q: ブラウザが自動で開かない

  A: ブラウザのアドレスバーに
     http://127.0.0.1:8000  と
     直接入力してアクセスしてください。

     ※ デスクトップ環境がない場合(SSH接続など)は
       自動で開きません。

  ─────────────────────

  Q: 画像が生成されない / エラーになる

  A: 以下を確認してください:
     - config.env の NOVELAI_API_KEY が
       正しく設定されていますか？
     - NovelAI のサブスクリプションは
       有効ですか？（期限切れではないか）
     - インターネットに接続されていますか？
     - Anlas（消費ポイント）が残っていますか？
       ※ Opus プランなら通常サイズは無制限です

  ─────────────────────

  Q: APIキーがわからなくなった

  A: NovelAI のサイトにログインし、
     Account → 「Get Persistent API Token」
     で新しいキーを再発行できます。
     新しいキーを config.env に設定してください。

  ─────────────────────

  Q: セーブデータを別のPCに移したい

  A: backend/data/ フォルダをまるごとコピーして、
     移行先の同じ場所に上書きしてください。

  ─────────────────────

  Q: 「libssl」「libffi」などが見つからないと言われる

  A: 必要なシステムライブラリをインストールしてください:

     sudo apt update
     sudo apt install -y libssl-dev libffi-dev

     ※ ディストリビューションによってパッケージ名が
       異なる場合があります。
