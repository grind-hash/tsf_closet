============================================
  TSF Closet (Linux)  ─  更新手順
============================================

  TSF Closet をご利用いただき、
  ありがとうございます。

  このファイルでは、Ubuntu/Linux 環境での
  旧バージョンからの更新（アップデート）手順を
  説明しています。

  ※ 初めてご利用の方は「README_linux.txt」を
    お読みください。


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  更新前の準備
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  更新を始める前に、以下を行ってください。

  1. ゲームが起動中の場合は終了します

     - ターミナルで Ctrl+C を押す、または
     - 別のターミナルから ./stop.sh を実行

  2. 旧フォルダのバックアップを取ります

     以下の2つを安全な場所にコピーしてください:

     - config.env
       （APIキーや設定が書かれたファイル）

     - backend/data/ フォルダ
       （セーブデータや生成画像が入っています）

     例:
       cp config.env ~/backup/
       cp -r backend/data ~/backup/

     ※ バックアップがあれば、万一のときに
       元の状態に戻すことができます。


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  更新手順
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1. 新しいバージョンのアーカイブファイルを
     展開（解凍）します

     tar xzf tsf_closet_portable_vX.X.X_linux.tar.gz

     ※ 旧フォルダとは別の場所に展開してください
     ※ フォルダのパスに日本語や特殊文字を
       含めないでください
       例: ~/games/tsf_closet_new/

  2. 旧フォルダから「config.env」を
     新しいフォルダにコピーします

     cp ~/old_folder/config.env ~/new_folder/

     コピー先にすでに config.env がある場合は
     上書きしてください。

  3. 旧フォルダから「backend/data/」フォルダを
     まるごと新しいフォルダにコピーします

     cp -r ~/old_folder/backend/data ~/new_folder/backend/

     ※ 既存の data フォルダがある場合は
       上書きしてください。

  4. スクリプトに実行権限を付与します

     chmod +x start.sh stop.sh

  5. 新しいフォルダ内で start.sh を実行します

     cd ~/new_folder
     ./start.sh

  6. ブラウザでゲーム画面が表示されたら
     更新完了です

     ※ ブラウザが開かない場合は
       http://127.0.0.1:8000 にアクセスしてください


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  config.env の新しい設定項目について
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  バージョンアップで config.env に
  新しい設定項目が追加されることがあります。

  旧バージョンの config.env をそのまま使う場合、
  新しい項目は初期値で動作しますので、
  通常はそのままで問題ありません。

  新しい設定項目を確認・変更したい場合は、
  以下の手順で確認できます:

  1. 新しいフォルダの config.env（上書き前）と
     旧フォルダの config.env を見比べます

     diff ~/old_folder/config.env ~/new_folder/config.env

  2. 新しい方にだけある項目があれば、
     必要に応じて旧 config.env に追記します

  ※ 設定項目の意味は README_linux.txt の
    「設定のカスタマイズ（上級者向け）」を
    参照してください。


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  言語の切り替え
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  このゲームは日本語と英語に対応しています。
  言語を切り替えるには、ゲーム画面右上の
  ⚙（歯車）アイコン → 「言語」セクションで
  変更できます。

  ※ English is also available.
    See the Language section in Settings (⚙).

  トラブルシューティング
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Q: 更新後にゲームが起動しない

  A: 以下を確認してください:
     - アーカイブを展開してから
       start.sh を実行していますか？
     - config.env を正しくコピーしましたか？
     - start.sh に実行権限がありますか？
       chmod +x start.sh

  ─────────────────────

  Q: 更新後にセーブデータが消えた

  A: backend/data/ フォルダを
     コピーし忘れていないか確認してください。
     バックアップから data フォルダを
     新しいフォルダの backend/ 配下にコピーすれば
     復元できます。

     cp -r ~/backup/data ~/new_folder/backend/

  ─────────────────────

  Q: 更新後に画像生成でエラーが出る

  A: 以下を確認してください:
     - config.env の NOVELAI_API_KEY が
       正しく設定されていますか？
     - NovelAI のサブスクリプションは
       有効ですか？

  ─────────────────────

  Q: 旧バージョンに戻したい

  A: バックアップしておいた旧フォルダを
     そのまま使えば元に戻せます。
     旧フォルダの start.sh を実行してください。
