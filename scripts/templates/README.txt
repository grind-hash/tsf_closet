============================================
  TSF Closet  ─  はじめにお読みください
============================================

  TSF Closet をダウンロードいただき、
  ありがとうございます。

  このファイルでは、初めて利用する方向けに
  セットアップから遊び始めるまでの手順を
  説明しています。


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  初回セットアップ（はじめに必ず行ってください）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  このゲームでは、画像やテキストの生成に
  NovelAI のサービスを利用します。
  遊ぶには NovelAI の「APIキー」が必要です。

  ── NovelAI APIキーの取得方法 ──

  1. ブラウザで NovelAI 公式サイトにログインします
     https://novelai.net

  2. 画面左上の歯車アイコンをクリックして
     「アカウント」設定を開きます

  3. 「永続的APIトークンを取得」をクリックします

  4. 表示された長い文字列（pst- で始まるもの）が
     APIキーです。これをコピーしてください

     ※ APIキーは一度しか画面に表示されません。
       メモ帳などに控えておくことをお勧めします。
     ※ このキーは他人に教えないでください。

  ── config.env への設定方法 ──

  1. このフォルダ内にある「config.env」ファイルを
     右クリック → 「メモ帳で開く」を選びます

     ※「プログラムから開く」と聞かれた場合は
       「メモ帳」を選んでください

  2. ファイルの中に以下のような行があります:

       NOVELAI_API_KEY=your_api_key_here

  3. 「your_api_key_here」の部分を、
     先ほどコピーしたAPIキーに書き換えます

     例:
       NOVELAI_API_KEY=pst-abc123xxxxx...

     ※ = の前後にスペースを入れないでください
     ※ APIキーを「"」や「'」で囲まないでください

  4. 書き換えたら、メモ帳の
     「ファイル」→「上書き保存」で保存します

  これで初回セットアップは完了です!


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  ゲームの起動方法
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1. このフォルダ内の「start.bat」を
     ダブルクリックします

  2. 黒いウィンドウ（コンソール）が開き、
     しばらく待つと準備が整います

  3. 自動的にブラウザが開き、
     ゲーム画面が表示されます

  4. もしブラウザが開かない場合は、
     ブラウザのアドレスバーに
     以下のURLを直接入力してください:

       http://127.0.0.1:8000


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  言語の切り替え
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  このゲームは日本語と英語に対応しています。
  初期設定は日本語です。

  言語を切り替えるには:

  1. ゲーム画面の右上にある
     ⚙（歯車）アイコンをクリックします

  2. 設定画面の「言語」セクションで
     お好みの言語を選択します

  ※ English is also available.
    See the Language section in Settings (⚙).


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  ゲームの終了方法
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  以下のいずれかで終了できます:

  - 黒いウィンドウ（コンソール）の
    右上の×ボタンをクリック

  - 黒いウィンドウ上で
    キーボードの Ctrl キーを押しながら C を押す


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  遊ぶのに必要なもの
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  - Windows 11 のPC（64bit）
  - インターネット接続
  - NovelAI の有料プラン（サブスクリプション）
  - Microsoft Visual C++ 再頒布可能パッケージ

  ※ NovelAI の有料プランに加入していないと
    画像生成やテキスト生成が行えません。
  ※ 画像生成ごとに NovelAI の Anlas を消費します。
    Opus プランでは通常サイズの生成が無制限です。

  ── Visual C++ 再頒布可能パッケージについて ──

  このゲームの動作には
  「Microsoft Visual C++ 再頒布可能パッケージ」
  が必要です。

  多くのPCにはすでにインストールされていますが、
  起動時に「DLL load failed」や
  「指定されたモジュールが見つかりません」
  というエラーが出る場合は、
  以下のURLからインストールしてください:

    https://aka.ms/vs/17/release/vc_redist.x64.exe

  ※ 上のURLをブラウザに貼り付けると
    ダウンロードが始まります。
  ※ ダウンロードした exe ファイルを実行し、
    画面の指示に従ってインストールしてください。
  ※ インストール後、PCの再起動は不要です。


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  NovelAI のプランについて
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  このゲームで快適に遊ぶには
  「Opus」プランをお勧めします。

  理由:
  - 通常サイズの画像生成が無制限
  - テキスト生成（キャラクターの心境表示）も利用可能
  - Anlas（消費ポイント）の残量を気にせず遊べる

  Tablet / Scroll プランでも遊べますが、
  1回の画像生成ごとに Anlas を消費するため、
  月間の利用量に注意が必要です。


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  設定のカスタマイズ（上級者向け）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  config.env をテキストエディタで編集することで、
  以下のような設定を変更できます。
  通常はそのままで問題ありません。

  PORT
    サーバーのポート番号です（初期値: 8000）。
    他のソフトと競合する場合のみ変更してください。

  LOG_LEVEL
    ログの詳細度です（初期値: info）。
    問題が発生した場合に debug に変更すると、
    詳しい情報がコンソールに表示されます。

  NOVELAI_STEPS
    画像生成のステップ数です（初期値: 28）。
    大きくすると品質が上がる場合がありますが、
    生成時間が長くなります。

    ★ 重要 ★
    Opus プランでも、ステップ数を 29 以上に
    すると Anlas を消費するようになります。
    28 以下であれば Anlas 消費なしで生成できます。
    特にこだわりがなければ 28 のままにしてください。

  NOVELAI_I2I_STRENGTH
    画像の変化の度合いです（初期値: 0.90）。
    1.0 に近いほど大きく変化します。
    0.0 に近いほど元画像に近い結果になります。


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  データの保存場所
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  ゲームのセーブデータや生成した画像は、
  以下のフォルダに保存されます:

    backend\data\

  データをバックアップしたい場合は、
  このフォルダをまるごとコピーしてください。


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  よくある質問（トラブルシューティング）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Q: start.bat をダブルクリックしても動かない

  A: 以下を確認してください:
     - ZIP ファイルを展開（解凍）してから
       start.bat を実行していますか？
       ZIP の中から直接実行すると動きません。
     - フォルダのパス（場所）に日本語や
       特殊文字が含まれていませんか？
       例: C:\ゲーム\ など
       → 英数字のみのフォルダに置いてください
         例: C:\Games\TSFCloset\

  ─────────────────────

  Q: 「ポートが使用されています」と表示される

  A: 他のソフトが同じポート（8000番）を
     使っている可能性があります。
     config.env の PORT を別の番号
     （例: 8080）に変更してください。

  ─────────────────────

  Q: ブラウザが自動で開かない

  A: ブラウザのアドレスバーに
     http://127.0.0.1:8000  と
     直接入力してアクセスしてください。

  ─────────────────────

  Q: 画像が生成されない / エラーになる

  A: 以下を確認してください:
     - config.env の NOVELAI_API_KEY が
       正しく設定されていますか？
     - NovelAI のサブスクリプションは
       有効ですか？（期限切れではないか）
     - インターネットに接続されていますか？
     - Anlas（消費ポイント）が残っていますか？
       ※ Opus プランなら通常サイズは無制限です

  ─────────────────────

  Q: APIキーがわからなくなった

  A: NovelAI のサイトにログインし、
     Account → 「Get Persistent API Token」
     で新しいキーを再発行できます。
     新しいキーを config.env に設定してください。

  ─────────────────────

  Q: セーブデータを別のPCに移したい

  A: backend\data\ フォルダをまるごとコピーして、
     移行先の同じ場所に上書きしてください。
